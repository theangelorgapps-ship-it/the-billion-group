# The Billion Group

The official responsive website for The Billion Group, built with TanStack Start, React and TypeScript.

```bash
npm install
npm run dev
```

The development server is fixed to `http://127.0.0.1:3001` so it stays isolated from other local projects.

## GitHub Pages

Pushes to `main` are typechecked, prerendered and deployed automatically to:

`https://theangelorgapps-ship-it.github.io/the-billion-group/`
